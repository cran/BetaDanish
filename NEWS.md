# BetaDanish 0.1.0

## New features

* Added density, distribution, quantile, random generation, survival, and hazard functions for the Beta-Danish distribution.
* Added maximum likelihood estimation for complete and right-censored survival data.
* Added support for the four-parameter Beta-Danish model and the three-parameter submodel.
* Added model comparison tools using log-likelihood, AIC, BIC, and goodness-of-fit measures.
* Added advanced survival modeling modules, including AFT regression, cure models, and competing risks analysis.
* Added built-in benchmark datasets for survival and reliability applications.
* Added diagnostic plotting methods, including survival, hazard, density, P-P, and Q-Q plots.

## Documentation

* Added package-level documentation.
* Added a vignette introducing the Beta-Danish modeling workflow.
* Added README examples for installation, model fitting, model comparison, cure models, and diagnostic plotting.
